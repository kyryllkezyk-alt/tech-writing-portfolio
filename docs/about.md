# About

I'm Kyryll Kezyk, a technical writer and localization lead based in northern Israel.

For fifteen years I've worked where software meets language: running a Hebrew localization
division, auditing translation quality for global vendors, evaluating AI model output, and writing
the guidelines, glossaries and process documentation that distributed teams depend on.

## What I bring to a docs team

- **Writing for translation.** I write source text that localizes cleanly, because I've spent years
  on the receiving end of text that didn't.
- **Right-to-left expertise.** Hebrew and Arabic layout, bidirectional text, and the edge cases that
  break UI strings.
- **Quality systems.** Style guides, terminology management, review workflows and measurable
  quality metrics.
- **Docs-as-code.** Markdown, Git, static site generators, CI checks and prose linting.
