# Technical writing portfolio

I document software that has to work in more than one language. Fifteen years across
localization operations, translation quality and content engineering taught me to write reference
material the way a build system reads it: unambiguous, testable, and structured to survive
translation into thirty locales without a rewrite.

**This site is itself the sample.** Every page is version-controlled Markdown, linted on pull
request, built with `mkdocs build --strict`, and deployed by GitHub Actions on merge.
